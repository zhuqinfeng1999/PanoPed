# Figure provenance and rights

`gallery.jpg` and `real_overview.jpg` are publication-size derivatives of fixed PanoPed-S Unreal Engine frames and consented PanoPed-R frames, with released annotation curves overlaid. They are provided to illustrate the paper and are **not** additional training data or an invitation to redistribute the source frames. The source datasets' respective research-use licenses and participant-consent restrictions govern the underlying images. The repository's CC BY-NC-SA code license does not override those rights or any upstream synthetic asset license.

The real display derivatives were regenerated from SHA-checked original release frames for the non-anonymous arXiv edition. The submitted anonymous ICLR figures remain pixelated and separate.
